# speedtest

Замеряет скорость загрузки файла: 10 последовательных GET-запросов к одному URL, итог в MB/s.

## Запуск

Нужен Python 3.9+, зависимостей нет: подойдёт и системный `python3` на macOS.

```bash
python3 speedtest.py https://esahubble.org/media/archives/images/large/heic1501a.jpg
```

Снимок Hubble весит 26,8 МБ, за 10 запросов скачается около 270 МБ. Реальный прогон:

Тесты работают без сети, на локальном HTTP-сервере: `python3 -m unittest -v`

Если Python установлен с python.org и запрос падает с `CERTIFICATE_VERIFY_FAILED`, запустите `Install Certificates.command` из папки Python в Applications.

## Что измеряется

- **Время запроса** — от начала запроса до последнего байта тела. Каждый запрос открывает новое соединение, поэтому в это время входят DNS, TCP и TLS, а также редиректы.
- **Объём** — байты тела ответа в том виде, в каком они пришли (сжатие не запрашивается).
- **Скорость** — суммарный объём / суммарное время. MB = 10⁶ байт, в скобках Mbit/s.
- Если тело короче `Content-Length` (обрыв) или запрос завершился ошибкой — сообщение в stderr и код выхода 1.
- Таймаут 30 с действует на каждую сетевую операцию (соединение, чтение), а не на весь запрос: медленная, но живая загрузка не прерывается.
- Это скорость в один поток до конкретного сервера или CDN, а не «скорость интернета». На маленьком файле рукопожатия занижают результат, поэтому берите файл от 20 МБ.
