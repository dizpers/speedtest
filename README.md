# speedtest

Замеряет скорость загрузки: 10 последовательных GET-запросов к одному URL, итог в MB/s.

## Запуск

Нужен Python 3.9+, зависимостей нет: подойдёт и системный `python3` на macOS.

```bash
python3 speedtest.py https://esahubble.org/media/archives/images/large/heic1501a.jpg
```

Снимок Hubble весит 26,8 МБ, всего скачается около 270 МБ. Реальный прогон:

## Что измеряется

- **Время запроса** — от начала запроса до последнего байта тела. Каждый запрос открывает новое соединение, поэтому сюда входят DNS, TCP, TLS и редиректы.
- **Объём** — байты тела ответа в том виде, в каком они пришли (сжатие не запрашивается).
- **Скорость** — суммарный объём / суммарное время. MB = 10⁶ байт, в скобках Mbit/s.
- При обрыве (тело короче `Content-Length`) или ошибке запроса — сообщение в stderr и код выхода 1. Таймаут 30 с действует на каждую сетевую операцию, а не на весь запрос.
- Это скорость в один поток до конкретного сервера или CDN, а не «скорость интернета». На маленьких файлах рукопожатия занижают результат, поэтому берите файл от 20 МБ.
